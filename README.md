Title:

Odd Integers Sum till 200


Purpose:
 The Purpose of this project is to calculate the sum of odd integers up to 200 numbers.
How to run the program:
This program is automated you just have to run the program and the sum of first 20 odd integers would be calculated itself.
Example:
Input:
 This program do no take input from the user it simply runs when run button is pressed.
Output:
The sum of first two hundred odd integers = 10000
